# docs/design — эталонные макеты

Импортировано из Claude Design проекта
**«CRM визуальный язык: расписание кабинетов»**
(`d429f8c5-bedb-4584-a3ed-d5bd915fdd7b`, владелец Gasan).

Это `.dc.html` — формат Claude Design Canvas: разметка внутри `<x-dc>`,
данные и цвета подставляются шаблоном `{{ … }}` из `<script type="text/x-dc">`
внизу файла. Открывать их как обычный HTML нельзя (нужен рантайм `support.js`);
здесь они лежат **как эталон вида**, по которому верстаются экраны в `app/`.

## Что реально было в проекте на момент импорта

| Файл | Что это |
|---|---|
| `Сегодня.dc.html` | **выбранный** экран «Сегодня» — три карточки кабинетов + список свободных окон (вариант 1b), с сайдбаром и шапкой |
| `Сегодня - 3 подхода.dc.html` | разведка: 1a поток статусов · 1b три карточки · 1c лента событий |
| `Canvas.dc.html` | пустой холст-обёртка |
| `support.js` | рантайм Design Canvas (не часть визуального ТЗ, не сохраняли) |

**Чего в проекте НЕТ:** `Диалоги`, `Карточка пациента`, `tokens.css`,
`DESIGN.md`. Эти макеты в источнике отсутствуют — их нельзя импортировать.

## Визуальный язык, считанный с макета «Сегодня»

- Шрифты: **Onest** (интерфейс), **JetBrains Mono** (числа и время).
- Фон приложения `#FBFBFC`, панели/карточки `#FFFFFF`.
- Текст: `#15161B` основной · `#565B66` вторичный · `#868C97` приглушённый ·
  `#A7ADB7` слабый.
- Границы: `#E6E8EC` карточки · `#EFF1F4` внутренние разделители.
- Акцент: **`#4B44C7` (индиго)**. Опции темы в макете: `#4B44C7`,
  `#2A5CD6`, `#9A2C5B`, `#B0532A`.
- Скругления: карточки 12–14, кнопки/поля 8, пилюли 20.
- Акцент работает в: активном пункте навигации, кнопке «+ Запись»,
  точке первичного пациента, **и ближайшем свободном окне** (сплошная
  заливка акцентом, остальные окна — светлый тон акцента).
- Горизонтальной шкалы времени по кабинетам нет — сознательно убрана.
